● 🔧 Zotero Setup on Windows 11

  Step 1: Install & Configure Zotero

  1. Download Zotero:
    - Go to https://www.zotero.org/download/
    - Download Zotero 6 or 7 for Windows
    - Install with default settings
  2. Find Your Zotero Data Directory:
    - Open Zotero → Edit → Preferences → Advanced → Files and Folders
    - Note the "Data Directory Location" (usually: C:\Users\[username]\Zotero)
    - This path should match what's in your config/settings.yml
  3. Get API Key:
    - Go to https://www.zotero.org/settings/keys
    - Click "Create new private key"
    - Give it a name like "Literature Database"
    - Check "Allow library access" and "Allow write access"
    - Copy the generated key

  Step 2: Update Configuration

  Update your config/credentials.yml with your API key:

  zotero:
    api_key: "YOUR_ACTUAL_API_KEY_HERE"

  And verify your config/settings.yml has the correct Zotero path:

  zotero:
    windows_path: "C:/Users/[your-username]/Zotero"  # Update this path
    library_id: "[your-user-id]"  # Found in Zotero URL
